Créer les clés des notifications

Cette page fabrique deux clés sur ton ordinateur, sans rien envoyer sur internet. Ouvre-la en double-cliquant sur le fichier (pas besoin de la mettre sur GitHub).

1. Clé publique : à coller dans config.js (ligne vapidPublicKey).
2. Clé privée : à coller UNIQUEMENT dans Supabase (secret VAPID_PRIVATE_KEY).

La clé privée ne doit jamais être écrite dans config.js, sur GitHub, ni envoyée dans un message. Une fois collée dans Supabase, ferme cette page. Si tu régénères les clés, il faut réactiver les notifications sur chaque appareil.
